- White regions = permitted routing space.
- Black regions = walls, barriers, obstacles, or inaccessible space.
- Routes must remain entirely within white regions.
- Routes must never touch, enter, overlap, or cross black regions.

All coordinates are percentages relative to the image dimensions.

[O] Objective

Create a valid routing network that connects every antenna marker into a continuous network and ensures the network reaches at least one starting point.

[R] Routing Rules

Connectivity
- Every antenna marker must be connected.
- The routing network must connect to at least one starting point.
- No disconnected route fragments.

Network Construction
- Antenna markers may be used as routing nodes.
- Prefer connecting nearby antenna markers together first.
- Prefer shared routing paths.
- Prefer:
  Start → Antenna → Antenna → Antenna
  over:
  Start → Bend → Bend → Individual Antenna
- Do not create separate home-run routes for every antenna unless necessary.

Geometry
- Use horizontal and vertical segments only.
- No diagonal segments.
- Every connection represents exactly one straight segment.
- A direct connection is valid only if either xPercent or yPercent remains unchanged.

Obstacle Avoidance
- Treat all black regions as absolute barriers.
- Before creating a connection, verify the entire segment remains inside white space.
- Reject any segment that touches or crosses black space.
- If a direct segment is blocked, create bend points and route around the obstacle.

Bend Points
Create a bend point only when:
- The route changes direction.
- A route branches.
- Multiple routes join.
- An obstacle must be bypassed.

New bend points:
- ID must begin with "bend_".
- Must be inside white space.
- Must be used by at least one connection.

Existing Bend Points
- Reuse existing bend points when useful and valid.
- Do not use an existing bend point if reaching it requires crossing black space.

Routing Priority
1. Never cross, touch, or enter black regions.
2. Connect every antenna marker.
3. Connect the antenna network to at least one starting point.
4. Keep all segments inside white space.
5. Prefer antenna-to-antenna connections.
6. Reuse shared routes.
7. Use bend points only when required.
8. Minimize unnecessary route length.
