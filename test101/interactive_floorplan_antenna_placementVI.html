Antenna Placement & Wiring Tool

Position Pink Arrow (Point 0) start feed, place antenna markers, assign custom aliases, route cable lines, and save checkpoints.

User Guide:

• Pink Arrow (Point 0): Feed start position & direction. Drag to move. Right-click to Set Alias, Rotate (+45°), or Delete.

• Red Antenna Markers: Click Add Red Marker or drag to place. Right-click to change Number or Alias.

• Cable Wiring Lines: Click Connect Mode, then click Point 0 or any red marker sequentially to create cable runs.

• Push/Pull Bends: Click any line segment to insert blue handles and route around walls. Right-click bend handle to remove.
